# Historical packages

These packages are archived for reference. Use the [current package](../../dist/) for installation.

Versions 1.0.0, 1.0.1, 1.1.0 and 1.2.0 were development builds before release numbering reset to 1.0. Version 1.1 introduced Auto FFA; 1.2 added the compact attached panel and short messages. Version 1.3 makes dungeon parties use Group Loot. No development diagnostics package is shipped here.
